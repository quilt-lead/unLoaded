Calc package
Upload a calc package PDF, or press Load sample.
Feed in a BIM model and a calc package
The model becomes an element graph with load-path edges, the package is split into calcs, and every element is linked to the calcs that cover it - with the evidence, a confidence you can confirm or reject, and the downstream calcs that go stale when something changes.
Hackathon v1. Mapping is deterministic (marks, mark ranges, mark families, section sizes, element type) and every link shows the text it came from. Every upload is stored as a revision. Sample building and calc package are synthetic.
