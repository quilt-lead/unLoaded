# Structural Calculation & Element Graph Viewer (React + TypeScript)

Links a structural model (IFC) to the calculations that design it (calc package PDFs): every beam, column,
slab, connection and footing is mapped to the calcs that name it, with the matched text highlighted on the
original page as evidence. Views: **Element Graph**, **Calculation Graph**, **3D Model** (real IFC
geometry) and **PDF Calcs**, plus review decisions, impact ("what goes stale if this changes / is removed")
and a revision diff.

**Frontend only.** There is no server: IFC parsing, PDF text extraction and mapping run in the browser
(mapping in a Web Worker), and projects are stored in the browser (IndexedDB). Models and calc packages
never leave the machine. Share a project with **Project → Save project file** (one `.calcgraph.json`).

## Quick start

Full setup, including Git LFS for PDFs: [setup.md](setup.md).
```bash
git lfs install  # once per machine; PDFs are stored in Git LFS
npm install      # npm workspaces; postinstall copies web-ifc.wasm and the samples into public/
npm run dev
npm test         # app + package tests
npm run smoke    # IFC -> element graph summary in Node
```

**Load sample** uses a synthetic office building and its calc package, generated by the Python reference
tooling (generated, not committed):

```bash
cd tools/calcgraph-reference && uv run python -m synth.generate && cd ../.. && npm run assets
```

The **Harborview A/B demo** (two legacy JSON revisions in `data/`, with invented documents shown
labelled as demo data) needs nothing extra.

## Pipeline

```
IFC ──> @unloaded/ifc-parser ──> ModelInput ──> @unloaded/element-graph ──> ElementGraph ─┐
calc PDF ──> Web Worker: @unloaded/calc-mapper (pdf.js, segment, matcher, deps, impact, diff) ─┤
                                     local project store (IndexedDB) <────────────────────────┤
              elementGraphToBim (topology) + loadProject (calc data) ──> mergeProject ──> views
```

- `packages/ifc-parser`: what the IFC states (elements, marks, profiles, materials, levels, geometry
  summary, explicit relations).
- `packages/element-graph`: the topology source of truth. Elements and connections are nodes; edges are
  `connects`, `supports` (directed load path) and `part_of`, inferred from geometry where the file is silent.
- `packages/calc-mapper`: the calc engine (PDF text with word boxes, calc segmentation, the matcher with
  confidence tiers and evidence, calc → calc dependencies, impact, `diffGraphs`, the decision log).
- `src/`: the React app. See `docs/ARCHITECTURE.md` for the data flow, the store schema and the views.

Other model inputs reach the same element graph: a serialized element graph, a `ModelInput` JSON, or a
legacy BIM JSON (`src/loaders/legacyBimJson.ts`). A new format (Revit, Tekla, ETABS, ...) only needs to emit a
`ModelInput`. See `packages/*/README.md`.
