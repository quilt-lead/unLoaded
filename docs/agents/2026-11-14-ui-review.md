# Inspector close and workspace UI review

- **Status:** done
- **Branch:** prod
- **Owned files:** `src/App.tsx`, `src/components/{HeaderBar,FilterBar,DockableHudPanel,PropertyInspector,DocumentBrowser,RadialGraphCanvas}.tsx`, `src/index.css`, document helpers in `src/utils/graphEngine.ts`, `src/utils/colors.ts`, and associated new tests

## Decisions and causes

- The Inspector is now persistent in graph and 3D views: its close button and header hide toggle are removed. It remains hidden in the PDF view, where it is not used.
- Panel defaults and window resizing are constrained to the viewport. Changing a dock side remounts the panel in App, so a drag now commits that transition on release, after cleaning up pointer listeners. A docked panel stays docked during the gesture and floats at its default position on release. Continuous cross-container dragging would require lifted geometry or a stable portal; it is not implemented here.
- Graph pan detection uses total gesture displacement instead of each move event. Nodes/groups capture pointers, and cancellation no longer clears selection. Keyboard shortcuts ignore form editing and browser modifier keys; grouping only runs in the element graph.
- Element/category searches and calculation searches address different records. Crossing that boundary clears search/type; opening an explicit document also clears workspace filters so its target cannot be hidden. The document request counter remounts the browser for each explicit open, including repeated opens of the same document.
- Missing engineering values are not measurements: Inspector shows missing values honestly; absent/nonfinite utilization is neutral gray. Supplied zeros and overloads remain visible. Removed the invented bay/floor dimensions, strength, PDF mappings, and revision histories.
- The empty workspace omits a project-name placeholder; its 3D and calculation views use neutral labels until a model is imported.
- Interactive highlights use the CalcMap logo green (`#14AE5C`) with flat fills/outlines; structural category and diff-status colors remain distinct.
- The CalcMap mark is non-draggable; header import actions are labeled “Import” and “Compare,” and the header reset action was removed.
- Workspace-view selection slides with a smooth ease-out and reduced-motion fallback; the 3D viewer’s previous multicolor selection treatment is retained.
- CalcMap green remains the primary UI accent; near-white mint is limited to secondary 2D outlines and keyboard focus.
- Selected graph wires use white, not mint. Escape clears selection and the selected-document filter even when focus is in a search field; inline rename inputs still consume Escape to cancel their edit first.
- The sliding workspace-view indicator uses a neutral light gray instead of the brand green.
- The PDF calculation list and preview switch to a side-by-side layout at 900px, with 16px preview padding. The 3D viewport background matches the Element Inspector surface (`#2d3139`) instead of using a separate blue-gray.
- Interactive highlights use the CalcMap logo green (`#14AE5C`) with flat fills/outlines; structural category and diff-status colors remain distinct.
- The CalcMap mark is non-draggable; header import actions are labeled “Import” and “Compare,” and the header reset action was removed.
- `getAllDocumentsFlattened` now uses `null` for no filter and an empty Set for zero matches. It aggregates all document mappings before filtering, so a shared package retains its full mapping list. Revision selection is scoped to its document and defaults to the declared current revision.
- Keyboard-operable inspector/document rows, control labels, focus outlines, toast announcements, and reduced-motion styles were added. Header overflow remains reachable through horizontal scrolling.

## Follow-up findings

- The independently edited 3D viewer/control work was preserved. Its fit behavior still uses demo camera bounds without a selection, and secondary selections are not all included in fit bounds. Mesh disposal is also incomplete. See the separate 3D-controls note before changing those files.
- This is a focused functional review, not a complete responsive/accessibility certification. SVG graph selection and drag-only resizing still need broader keyboard alternatives.
