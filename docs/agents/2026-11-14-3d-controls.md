# 3D camera navigation

- **Status:** done
- **Branch:** prod
- **Owned files:** `src/components/Structural3DControls.ts`, `src/components/Structural3DControls.test.ts`, `src/components/Structural3DViewer.tsx`

## Decisions and causes

- Manual orbit, pan, drag zoom, and wheel input now update the displayed camera directly.
  The former `0.12` interpolation on every frame added acceleration lag and a long stopping
  tail, with different behavior at different refresh rates. Do not reintroduce shared
  smoothing for both direct manipulation and automatic camera moves.
- Fit/Reset alone use a 300 ms elapsed-time smoothstep transition, finish exactly, and honor
  reduced motion. Pointerdown or wheel cancels a transition at the displayed pose. Reset
  takes the shortest angular path even after multiple full orbits.
- Orbit sensitivity is 0.006 radians/pixel (previously 0.012). Pan uses the displayed
  radius and camera basis, so it follows the pointer in screen space.
- Click/drag discrimination measures distance from pointerdown, with a 3 px threshold.
  The previous per-event threshold mistook slow drags for clicks, causing selection and
  an unwanted automatic fit on release. Once a drag starts, returning to the start still
  counts as a drag. Capture, pointer identity, cancellation, and window blur prevent stuck
  gestures. Existing mouse button/modifier mappings are preserved.
- Navigation is separate from the React/WebGL renderer so real event handlers can be
  tested with a Three.js camera and Node EventTargets without adding a DOM test dependency.

## Verification

- The repository test suite and production build passed. All 16 controls regressions pass, covering direct
  response/stopping, slow drags, wheel units, interruption, pointer cancellation, and
  consistent transition progress at 30/60/144 Hz.
- Headless Chromium with the imported Harborview JSON reproduced coasting and failed
  transition takeover before the fix. The updated full 3D view and floating viewer pass
  orbit, pan, drag zoom, wheel, Fit/Reset interruption, click selection, and slow-drag
  selection suppression, with no page errors.
- Browser verification uses existing Playwright tooling outside this repository; no new
  dependencies were installed. Vite/esbuild require sandbox escalation on this Windows
  machine to resolve the project through its parent directories.
